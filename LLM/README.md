# 🧠 LLM Chatbot: AI-Powered Conversational Assistant for Cancer Support

An intelligent, domain-specific chatbot built to assist cancer patients and caregivers by answering queries, providing informative responses, and offering emotional support. Powered by advanced Large Language Models (LLMs).

---

## 🚀 Features

- 🔍 **Question Answering** from uploaded cancer-related PDF documents
- 🤖 **LLM-Powered Responses** using Hugging Face models like BART and FLAN-T5
- 🧬 **Semantic Search** using Sentence Transformers
- 📄 **PDF Parsing** for extracting relevant context
- 🌐 **REST API Backend** using Flask
- 📱 **Mobile Frontend** developed using Flutter
- 💬 **Contextual Chat** experience with LangChain and OpenAI
- 💾 **Persistent Storage** via SQLite for chat history and session management

---

## 🧰 Technologies Used :

### Backend
- Python
- Flask
- Hugging Face Transformers (`facebook/bart-large-cnn`, `google/flan-t5-base`)
- Sentence Transformers (`all-MiniLM-L6-v2`)
- LangChain
- Groq API
- PyMuPDF (PDF Parsing)
- SQLite

### Frontend
- Flutter (Dart)
- REST API integration
- User-friendly chat interface
